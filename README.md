## 与「腕带后端」仓库的关系

本作品的分析代码与另一个仓库 **[腕带后端](https://github.com/tyvtjhj/watch-agent-visable)** 中的
`daima/output/源代码/` **同源**。两者已逐一哈希比对：

| Notebook | 关系 |
|---|---|
| `健康检测预警模型.ipynb` | 完全相同 |
| `数据探索及可视化.ipynb` | 完全相同 |
| `活动模式分析模型及可视化.ipynb` | 完全相同 |
| `睡眠质量评估系统.ipynb` | 完全相同 |
| `市场现状.ipynb` | 内容相同，仅 notebook 元数据不同（kernelspec 的 `display_name`） |
| `数据预处理.ipynb` | 内容相同，仅元数据不同（Python 版本 `3.13.2` vs `3.12.4`、`nbformat_minor`） |

也就是说，**差异只存在于元数据，单元格内容一致**。

腕带后端仓库另有 4 个本仓库没有的 notebook：`AGENT.ipynb`、`步骤2.ipynb`、`模型.ipynb`、`改善(2).ipynb`。
如需完整代码，请同时查阅该仓库。

## 已知问题

1. **数据文件缺失。** 上表列出的 8 个数据文件均不在仓库内，未准备数据则所有 notebook 都无法运行。
2. **存在绝对路径。** `数据探索及可视化.ipynb` 中有一处 `D:/2025-04/SleepDataSet/cleaned_sleep_data_fixed_time.csv`，是作者本机路径，移植时需改为相对路径。
3. **notebook 输出体积偏大。** `数据探索及可视化.ipynb` 的 145 KB 主要来自单元格输出，会影响 diff 可读性。
4. **代码非最终版。** `市场现状.ipynb` 等文件的 notebook 元数据与腕带后端仓库中的版本不一致，说明这两份是不同时间点的快照。
